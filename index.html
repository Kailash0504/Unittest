LOC Reconciliation — Why the two numbers differ
Total LOC (Ground Truth)
-
Read directly from all test files. Accurate.

-

Sum Sprint Est. LOC
-
Estimate only; overstates. See below.
Avg LOC / File
-
Actual avg used in estimates.
Est. LOC Activity is an estimate, not a measurement. It is (files added + files modified) × avg LOC per file, and it overstates for four reasons: (1) those file counts come from each commit as a whole, so files outside the test project are included. (2) Edits to the same file in multiple sprints are counted again each time. (3) A branch-sync or merge shows inherited files as "add" ops, not newly written code. (4) Every changed file is charged the average file's LOC, whatever the real edit size. Treat it as a relative activity signal only, and trust Total LOC as the authoritative number. For exact per-sprint lines: git diff --stat <start-sha> <end-sha>
